# saunaControllerHomeAssistant
Sauna controller done in ESPHome in HomeAssistant

Hardware:
- esp32c6 controller
- 3 phase relay 40-480V with 3-32VDC input
- simple 3 row LCD for basic info

  
Enclosed in a custom made and 3d printed box.

Can be operated thru HomeAssistant widget or with physical buttons for local operation.
